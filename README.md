# Rutas Aéreas — Proyecto II, EIF207 Estructuras de Datos
Segundo proyecto del curso Estructuras de Datos donde se implementas los temas como grafos, recorrido entre grafos, algoritmo de Dijkstra, mapas hash, entre otros.

Universidad Nacional de Costa Rica — II Ciclo 2026

## Tecnologías
- **Lenguaje:** Java 17
- **Entorno:** Apache NetBeans (proyecto Maven)
- **Biblioteca gráfica:** Swing (incluida en el JDK)

## Cómo compilar y ejecutar
1. Abrir NetBeans: File > Open Project y elegir la carpeta `RutasAereas`.
2. Clic derecho en el proyecto > Clean and Build.
3. Run (F6). La clase principal es `cr.ac.una.rutasaereas.RutasAereas`.

Los datos se leen de `datos/aeropuertos.txt` y `datos/rutas.txt`.
